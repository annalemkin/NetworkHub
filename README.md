# The Ecopreneurship Network

A living map of the Stanford Ecopreneurship community — an interactive, force-directed
map of students and alumni across EcoSprint, EcoX, EcoSIF, EcoGlobal, and EcoRAMP.

**Live prototype:** https://annalemkin.github.io/NetworkHub/

- **Browse** — explore the whole room: dots are people, colored by sector, placed by shared work.
- **Student** — sign in to get a personalized map, ranked matches, and warm intros.

## About this build

This is a public, **email-free** prototype build for sharing and feedback. Contact details
are intentionally not included here; the full, login-gated version is maintained separately.

Static, client-side only — no server. Just `index.html` + `support.js` + `data.js`.
